# e-plantShopping

## Project Overview
**e-plantShopping** is a React-based front-end application for the "Paradise Nursery" online store. The application allows users to browse a variety of houseplants, add them to a shopping cart, and manage their cart before checkout.

The project includes:

- A **Landing Page** with a background image, company name, and "Get Started" button.
- A **Product Listing Page** displaying at least six unique houseplants across multiple categories, each with a thumbnail, name, price, and Add to Cart button.
- A **Shopping Cart Page** where users can view their selected plants, adjust quantities, remove items, and see the total cost.

This project demonstrates usage of:

- React and JSX components
- React Router for page navigation
- Redux Toolkit for managing the shopping cart state
- Responsive and interactive UI elements
- GitHub Pages deployment
